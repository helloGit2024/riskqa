# 风控问数系统 · 前置文档集（README）

> 这是一个**可被 AI 直接开工的项目**。文档把"不能靠 AI 猜"的东西先钉死，代码按 `docs/tasks.md` 分四个版本实现。

## 一、这套文档解决什么问题

没有这套文档，AI 会自己发明表结构、自己定接口字段、把"LLM 自由算数"当成聪明——每次发明得都不一样，且风控场景错一个数字就是事故。这套文档钉死的是：口径宪法（语义层 YAML）、数字纪律（fact_id + 三重校验闸）、硬规则 P-01..P-18、版本范围（V4.0—V4.3）。

**只有 `docs/constraints.md` 的硬约束与 `docs/spec.md` 第五节的业务流程必须你亲自确认**——其余由 AI 起草、你审。

## 三、三条铁律

1. **LLM 不碰数字**——数值只由 `calc/` 纯函数产出，叙事层只引用 `{{fact_id}}`（AGENTS P-03/06/07）。
2. **口径必须签字**——没有 Owner 签字的口径，系统不拿它算数给人看（P-05/P-13）。
3. **数据不出内网**——指标数据、日志、证据全部内网；LLM 默认本地模型（P-02）。

## 四、与既有代码的关系

本目录是既有四个单文件（`../问数Agent_*.py`，V1/V2/V3）的**工程化目标态**：
V4.0 将它们迁入 `src/riskqa/` 并包化（行为等价回归，不重写），原文件移入 `legacy/` 只读存档。
设计基线是三份既有文档（落地方案 / V3 持续运营 / 框架选型），本文档集是它们在工程规范下的展开。
