# 运维手册（ops-runbook.md）

> 上游：`docs/architecture.md` §五/§六；`docs/security.md`。下游：`docs/tasks.md` T-4.3.6（每条告警一次真实演练）。
> 部署形态：**内网单机**（systemd 或 nohup，不上 K8s，见 `AGENTS.md` 技术栈表）。
> 备份对象：`data/`（快照 + ops.db）整拷 + `config/` Git——**config/ 在 Git 里，天然有版本；data/ 靠本手册 §六**。

## 一、监控指标与阈值

### 1.1 业务指标

| 指标 | 含义 | 正常范围 | 异常时先看什么 |
|---|---|---|---|
| 请求量 | API/MCP 调用次数 | 3—5 人同时在线，日均百次级 | 掉零 = 入口断了（外壳/网络），不是引擎 |
| 错误率 | 5xx + 拒服（拒服要分开计，拒服不是错误） | 错误率 <1%；拒服率单独看 | 错误率涨 = 看 LLM 网关三态与 ops.db 锁 |
| 响应时间 P95 | 分快路/慢路两条线 | 快路 <2s；慢路 <60s（熔断值） | 快路慢 = 快照加载/权限注入；慢路慢 = LLM 或 SQL |
| 快路命中率 | 命中语义层占比 | 运营 3 个月目标 40%→80%+ | 命中率跌 = alias 被改坏或新问法没回流 |
| LLM 网关三态 | healthy / degraded / down | healthy | degraded = 本地模型抖动；down = 降级链在工作，问数不应中断 |
| 评审队列深度 | pending 状态的 review_record 条数 | <20 条 | 涨 = Owner 产能瓶颈（R-01），升级链应已自动触发 |

### 1.2 底层资源指标

CPU / 内存 / 磁盘 / SQLite 连接数。单机四个就够，不加监控系统（constraints §五：明确不做的技术里没有运维平台，也不做）。

- **磁盘是两个增长源**：`data/snapshots/`（12 个月滚动）+ `data/ops.db`（raw log 1 年保留期，P-12）。ops.db 只 INSERT 不 UPDATE，增速可估：按当前查询量 × 平均 log 大小外推，**超过预估 2 倍时先查是不是有外壳在刷接口**。
- ops.db 单文件超过 500MB 或 WAL 文件异常增大 → 按 §二 A6 处置。

## 二、告警规则与处置

> 每条告警都必须写"**看到它先做什么**"，否则半夜收到告警也不知道怎么办。
> 编号 `A1…An` 连续，**删除的编号留空不回填**。V4.2 起告警经企微/飞书 webhook 发送（T-4.2.7），
> V4.3 前先在日志里落 `alert` 表 + 邮件/IM 人工转发。

### A1 · 服务宕机 / 健康检查失败
**先做什么**：`ps aux | grep uvicorn`（或 `systemctl status riskqa`）看进程在不在 → 在的话看日志尾部 → 不在的话看是不是被 OOM 杀（`dmesg` 或系统日志）。
**不要做什么**：不要第一反应就重启（会丢掉现场）。**先留日志再重启。**

### A2 · 接口错误率飙升
**先做什么**：按端点拆分错误码——`E_LLM_UNAVAILABLE` 集中 = LLM 网关问题（转 A4）；`E_SQL_GATE_REJECT` 集中 = 有人/有外壳在发危险 SQL（转 SG-01 复盘）；`database is locked` = 并发写（ADR-0003 复核条件，检查是不是有第二个写方破了单写者纪律）。
**不要做什么**：不要把 5xx 改重试掩盖——本系统慢路自带 ≤2 轮修正，外层再套重试会放大 LLM 负载。

### A3 · 快路 P95 > 2s 持续 10 分钟
**先做什么**：拆解耗时（意图翻译 / 快照加载 / 权限注入 / 纯函数计算四段哪段涨了）。快路不调 LLM 生成，绝大多数是快照文件变大或权限注入 SQL 退化。
**不要做什么**：不要给快路加缓存兜底掩盖——口径数字必须每次从当前快照算（ADR-0006）。

### A4 · 本地 LLM 网关不可用（三态观测 degraded/down）
**先做什么**：确认降级链在工作（问数应自动降级不中断，T-4.1.7 验收标准）；看是模型服务挂了还是 endpoint 配错（A-01 假设的复核点）。
**不要做什么**：**不要为了"恢复服务"切云端 provider**——那是 P-02 一票否决事项，必须先补 ADR + 合规审批。宁可慢路停摆（快路不受影响），不破数据边界。
### A5 · 评审队列积压（pending >20 条或单条超 72h）
**先做什么**：看升级链状态机是否在自动运转（pending→reminded 72h→overdue 144h→shelved 504h，V3 §10）；shelved ≠ rejected，分开可查。队列积压的首因是 Owner 产能不是技术（R-01）——先叫人，别先改代码。
**不要做什么**：不要批量 approve 清队列——每次晋升都是口径入库，批量签字 = 口径失控。

### A6 · 磁盘将满 / ops.db 异常增大
**先做什么**：`du -sh data/snapshots data/ops.db` 定位增长源；快照超 12 个月的按滚动策略清理（**清理前确认没有进行中的报告依赖该快照**）；ops.db 只走保留期清理函数（删 ts<365d，T-4.0.3 实现），**禁止手工 DELETE**。
**不要做什么**：不要直接删 ops.db 文件"瘦身"——raw log 不可变是合规硬约束（P-12），删文件 = 审计链断裂。

### A7 · 备份失败 / 恢复演练失败
**先做什么**：当天重跑备份；查是磁盘满还是拷贝权限。恢复演练失败（T-4.3.6）比备份失败更严重——**没演练过的备份等于没有备份**，按故障处理，写实验记录。
**不要做什么**：不要只修演练不补真实故障复盘——演练失败暴露的就是真实故障时会中的坑。

## 三、故障处置总流程（第一反应清单）

1. **先看是不是只有某一个功能坏了** → 是的话只关那一个（慢路停了快路还能用），别整个下线。
2. **保留现场**：先抓日志再重启。日志路径：API 日志 + `alert` 表 + ops.db 的 audit_entry。
3. **降级优于中断**：能返回"暂时查不到"就不要返回 500；LLM 挂了走降级链（A4），不切云端。
4. **记录**：故障结束后写进 `docs/experiments/`（含"谁被叫醒、能不能处理"——T-4.3.6 验收要这个）。

## 四、回滚

### 4.1 应用回滚

单机部署，回滚 = 切回上一个 Git tag（镜像标签 = commit 短哈希的纪律在这里退化为 **Git tag**）：

```bash
git tag v4.1.0            # 上线时打
git checkout v4.1.0       # 回滚（config/ 同库，YAML 一起回）
# systemd: sudo systemctl restart riskqa；nohup: 重启进程
```

**YAML 回滚的特殊性**：口径变更走 Git 评审（P-05/P-15），所以代码回滚自动带回上一版口径——
这是"语义层在 Git 同库同权"设计的直接收益。

### 4.2 数据回滚

> ⚠️ 数据库变更**不许依赖回滚**——靠"拆两次发布"来保证任何时刻都能回退。
> 这是硬规则，见 `AGENTS.md`。

- **ops.db**：只追加不修改（P-12），没有"回滚"概念，只有"从备份恢复"（`data/` 整拷 + 校验 raw log 条数与保留期）。
- **快照文件**：不可变，新数据 = 新文件新 manifest，回滚 = 应用指回旧 manifest。
- **事实（fact 表）**：只 INSERT；历史 fact 永久可查（US-08：一年后"这个指标哪来的"一句话可答）。

## 五、容量与成本

| 项 | 当前 | 上限 | 到上限怎么办 |
|---|---|---|---|
| 磁盘（快照） | 12 个月滚动 | 按磁盘 70% 告警 | 清理超期快照（A6）；缩小快照列（先改 manifest 规范） |
| 磁盘（ops.db） | raw log 1 年保留 | 500MB 预警 | 保留期清理函数；仍超 = 查写入方（A6） |
| 模型资源 | 本地模型一个（内网 GPU 共享） | 无硬上限，争抢时 P95 涨 | ModelRouter 降档（归因强模型→叙事便宜模型→规则模板）；热度归因使调用递减 |
| 并发 | 3—5 人（constraints §2） | SQLite 单写者 | 超 3 并发写 = ADR-0003 复核条件，评估升 PostgreSQL |
| 成本（钱） | 内网单机 + 本地模型 | 电费/机器既有 | 无增量采购；切云端 provider 被 P-02 禁（无 ADR 不讨论） |

## 六、例行维护

| 频率 | 做什么 |
|---|---|
| 每天 | 看一眼告警（alert 表 / webhook）；LLM 网关三态 |
| 每周 | 看磁盘与 ops.db 增速趋势；快路命中率（运营健康度的领先指标） |
| 每月 | **备份恢复演练**（没演练过的备份等于没有备份）；保留期清理函数跑一次 |
| 每季 | 误晋升率抽查（目标 0，spec §3.2）；黄金题集全量回归（`make eval`） |
