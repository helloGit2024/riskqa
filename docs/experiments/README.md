# 优化实验记录（docs/experiments/）

> 目的：**回答"这次改动到底是进步还是退步"**。
> 没有记录的话，改了三周以后你会开始怀疑"是不是还不如原来"。
> 首篇实验记录由 T-4.0.10（V4.0 退出评审）写入；此后每次评估不达标后的改动都记这里。

## 实验记录模板（复制使用）

---
# 实验：YYYY-MM-DD 【优化项名称】

## 改了什么
具体到参数 / 代码位置。不要写"优化了检索"。

## 为什么改
从哪次评估 / 哪个坏例子里得到的判断？（引用黄金题号或 log QID）

## 结果对比

| 指标 | 改之前 | 改之后 | 变化 |
|---|---|---|---|
| | | | |

> **纪律：必须用同一套冻结题库跑。** 换了题目的对比数字是无效的。
> 单次跑的差异不算数——要跑 ≥3 次看波动范围，差异要大于波动才算真改善。

## 失败案例
改完之后**变差**的题目有哪些？这一节必须写，只写变好的部分是自欺欺人。

## 决策
- [ ] 采纳
- [ ] 回滚
- [ ] 保留但需要继续观察

## 复盘
这次的判断依据是否成立？有没有意外发现？
---

## 三条纪律

1. **必须先记、再改**。改完再补记，一定会漏掉"改之前是多少"。
2. **同一套题库**。换题对比 = 无效。
3. **失败也要记**。失败记录的价值往往高于成功记录——它防止你三个月后再踩一次。

## 优化杠杆的性价比参考（按"见效 / 成本"排序，本项目版）

| 杠杆 | 见效 | 成本 | 备注 |
